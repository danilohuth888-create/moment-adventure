# MOMENT v0.4 — Pixel Survivors Update

MOMENT ist jetzt eine bewusst pixelige Offline-PWA mit einem arcadigen Action-RPG-Look.

## Enthalten

- pixeliges Rendering mit kleiner interner Aufloesung
- Survivors-artiges Kampfgefuehl
- zwei Klassen: Arkanist und Waechter
- 5 Raeume mit Bosskampf
- Upgrades pro Lauf + dauerhafte Schmiede-Upgrades
- Zuflucht, Garten, Export/Import des Spielstands
- kompletter Offline-Betrieb nach dem ersten Laden

## Deployment

Der Ordner ist fuer das bestehende GitHub-Repository `danilohuth888-create/moment-adventure` vorbereitet.
Fuer Updates auf dem MSI: `UPDATE_GITHUB.ps1` ausfuehren.
